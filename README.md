# Data Cleaning Bootcamp

Foundational course exercises in Python, NumPy, pandas and visualization. This repository is a learning archive, not a collection of independent projects.

| Directory | Focus |
| --- | --- |
| `python/` | Python fundamentals |
| `numpy/` | Arrays and numerical exercises |
| `pandas/` | DataFrame operations and tabular data practice |
| `data_visualization/` | Matplotlib and Seaborn exercises |
| `exploratory_data_analysis/` | Historical EDA exercises |
| `feature_engineering/` | Historical cleaning exercises |

For the maintained versions of overlapping work, see [Exploratory Data Analysis](https://github.com/sremresimsek/exploratory-data-analysis) and [Feature Engineering & Cleaning](https://github.com/sremresimsek/feature-engineering-and-cleaning). Historical copies are retained for now to avoid breaking course exercises.

## Run locally

Create a virtual environment, install `python -m pip install -r requirements.txt`, and open `python -m jupyter notebook`. Run notebooks from their own directories. See [DATA_SOURCES.md](DATA_SOURCES.md).

## Limitations

This is an educational archive. Dependency compatibility and full execution have not been verified. Some notebooks contain historical outputs. Hotel booking contact fields require provenance/privacy verification before public redistribution.
